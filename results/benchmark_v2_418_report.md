# Báo Cáo Benchmark Mở Rộng Toàn Hệ Thống (418 Ảnh / 552 Instances / 55 Lớp)

> [!IMPORTANT]
> **Tóm tắt điều hành (Executive Summary)**
> Đánh giá toàn diện hệ thống **YOLOv10b + MobileSAM (Config C) + Depth Anything V2 + Volume (`A1–A5 + B1–B2 + C1–C6`)** trên tập dữ liệu mở rộng gồm **418 ảnh** (**552 GT instances**, **55 lớp món ăn** có nhãn phân đoạn, **500 nhóm khối lượng đơn/gộp** + **6 bữa `BunDau` tổng bữa**, tổng **415 bữa ăn** có khối lượng thực tế đầy đủ).
> - **Nhận diện ArUco 4x4 (30 mm):** Thành công **402 / 418 ảnh (`96.2%`)**, neo độ sâu thành công **359 / 418 ảnh (`85.9%`)**.
> - **Phân đoạn MobileSAM (Config C):** Micro mIoU = **`0.9450`**, Macro mIoU = **`0.9489`**, Boundary IoU = **`0.5199`**, Seg Success (`IoU >= 0.50`) = **`100.0%`**, Median P50 Latency = **`182.2 ms`** (Mean **`325.8 ms`**), Peak VRAM = **`313.2 MiB`**.
> - **Ước lượng Khối lượng (`Volume A1–A5 + B1–B2 + C1–C6`) trên 500 nhóm khối lượng:**
>   - **Oracle GT Mask:** MAE = **`64.84 g`** (giảm từ `96.90 g`), MAPE = **`30.86%`** (giảm từ `54.05%`), RMSE = **`95.46 g`** (giảm từ `159.86 g`). **Full-Meal (`415` bữa):** MAE = **`74.59 g`**, MAPE = **`28.77%`**.
>   - **Oracle MobileSAM Config C:** MAE = **`64.51 g`** (giảm từ `97.01 g`), MAPE = **`30.70%`** (giảm từ `55.03%`), RMSE = **`94.22 g`**. **Full-Meal (`415` bữa):** MAE = **`74.32 g`**, MAPE = **`28.82%`**.
>   - **End-to-End (`YOLO + MobileSAM C`) Matched-Only (`437` nhóm):** MAE = **`75.34 g`** (giảm từ `104.62 g`), MAPE = **`35.88%`** (giảm từ `54.46%`).
>   - **End-to-End Full-Meal (`415` bữa ăn):** MAE = **`91.32 g`** (giảm từ `121.45 g`), MAPE = **`40.48%`** (giảm từ `54.11%`).
