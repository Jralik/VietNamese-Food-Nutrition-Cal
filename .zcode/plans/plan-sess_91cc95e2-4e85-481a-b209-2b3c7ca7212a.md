# Kế hoạch Cải tạo Giao diện FoodDetector AI

## Định hướng thiết kế (được bạn trao quyền sáng tạo)
**Concept "Bếp Việt về đêm — Dark Amber"**: chủ đề tối ấm (khác biệt với navy lạnh của mẫu), giữ bản sắc vàng của dự án:
- Nền espresso ấm `#14110C` / card `#1E1913` / viền kính mờ `rgba(255,255,255,0.07)`
- Nhấn: gradient vàng amber `#FEC51C → #FF8A3D` (giữ brand màu cũ), chữ trắng ấm `#F5EFE6`
- Font **Be Vietnam Pro** (Google Font thiết kế riêng cho tiếng Việt, thay Montserrat)
- Traffic-light (xanh/vàng/đỏ) giữ nguyên vai trò nhưng tối ưu cho nền tối
- Glassmorphism card, bo góc lớn, số KPI gradient, scrollbar tùy chỉnh, responsive mobile

## Cấu trúc mới: 4 tab workflow toàn màn hình (theo mẫu, bạn đã chọn)
1. **🧬 Thể trạng & Mục tiêu** — form hồ sơ (tuổi/cân/chiều cao/vận động/mục tiêu) đưa từ sidebar vào đây, thẻ KPI (BMI + phân loại, TDEE, RDA Calo, Protein/Fat/Đường/Muối mục tiêu), **thước đo BMI gauge** có kim chỉ 4 vùng màu, thanh tiến độ phân bổ macro mục tiêu, **biểu đồ dự báo cân nặng 12 tuần** (Plotly, thuần toán học frontend: mục tiêu ±500 kcal/ngày)
2. **🍜 Quét món ăn** — radio chọn chế độ đầu vào: **🖼️ Demo (ảnh mẫu)** / 📁 Tải ảnh / 🎥 Video / 📷 Webcam / 📡 IP Camera. Kết quả ảnh được làm lại hoàn toàn:
   - KPI cards tổng dinh dưỡng (có ± sai số, thêm **Carbs** vào tổng)
   - **Biểu đồ tròn macro** (Protein/Fat/Carbs) + **thanh tiến độ so với RDA** của người dùng (calo/protein/đường/muối — đổi màu xanh→vàng→đỏ theo %)
   - **Bảng dataframe từng món** (món, khối lượng, thể tích, calo, protein, fat, đường, muối, tin cậy)
   - Card từng món dạng expander (ảnh crop + chip dinh dưỡng traffic-light, badge khẩu phần) — sửa luôn bug `background-color: "transparent"` ở utils.py:838
   - 3 nút tải: **Ảnh (PNG/JPG) + CSV + JSON** (JSON mới)
   - Đánh giá AI bữa ăn (giữ logic cũ, làm đẹp)
3. **💬 AI Nutritionist** — chat full-width cao hơn, giữ nguyên logic 4 nhà cung cấp (Gemini/Cerebras/OpenRouter/Cloudflare) + RAG, gợi ý dạng chip, tự động có ngữ cảnh từ Tab 1 + lần quét gần nhất
4. **📖 Về mô hình** — chuyển nội dung pages/dataset.py thành tab (thông tin YOLOv26, VietFood67, pipeline volume) theo theme mới

**Sidebar thu gọn**: brand + tóm tắt nhanh (BMI, RDA Calo dạng chip), cấu hình API key (expander), link GitHub. Hero banner: giữ ảnh ẩm thực + overlay gradient tối + chip glass thống số.

## Thay đổi file
| File | Thao tác |
|---|---|
| `.streamlit/config.toml` | theme dark amber (bg `#14110C`, secondary `#1E1913`, primary `#FEC51C`) |
| `assets/css/general-style.css` | **viết lại toàn bộ** (~800 dòng): design tokens, font Be Vietnam Pro, KPI card, gauge, progress bar, dataframe, chat, navbar, responsive |
| `ui_components.py` | **file mới**: hàm dựng HTML/biểu đồ tái sử dụng (kpi_row, bmi_gauge, progress_rda, donut_macro, traffic chip, hero, navbar) — khử ~3 chỗ HTML trùng lặp trong utils.py |
| `main.py` | viết lại shell app: 4 tab, sidebar mới, xóa code chết (`streamlit_navigation_bar`, `home_page/about_page`, CSS chú thích, bug `query_params.get(...)[0]` main.py:1116 — không còn cần query params) |
| `utils.py` | restyle các renderer kết quả (`detect_image_result`, `_display_detected_frame`, `detect_camera`, `detect_webcam`) dùng chung `ui_components`; dịch 100% nhãn/spinner/hướng dẫn sang tiếng Việt; thêm Carbs vào tổng dinh dưỡng |
| `assets/demo/*.jpg` | **mới**: copy 6 ảnh crop món ăn sẵn có từ `test_output/` (Phở, Bún bò Huế, Cơm tấm, Bánh mì, Bún chả, Cháo lòng) làm ảnh demo |
| Xóa file chết | `pages/about.py`, `pages/dataset.py` (chuyển nội dung vào tab), `assets/css/font.css` (không được nạp), bỏ `streamlit_navigation_bar` khỏi main.py + requirements.txt |

Không thêm thư viện mới (pandas, plotly đã có). Toàn bộ logic AI/detect/volume giữ nguyên — chỉ thay lớp trình bày.

## Kiểm thử
1. Chạy `streamlit run main.py` headless, theo dõi log không có exception
2. Dùng browser để kiểm tra từng tab: chọn demo ảnh → quét → xem KPI/donut/bảng/gauge, kiểm tra responsive và chat
3. Sửa lỗi phát hiện thấy, chạy lại đến khi ổn
